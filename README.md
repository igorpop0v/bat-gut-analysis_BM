# Bat gut microbiome and virome analysis

Reproducible bioinformatics workflows for the analysis of fecal samples collected from active and hibernating bats.

## Workflows

### 16S rRNA analysis

Analysis of bacterial and archaeal community composition using 16S rRNA amplicon sequencing data.

Code is located in:

`workflows/16s/`

### RNA virome analysis

Analysis of the RNA virome, including a separate component for bacteriophage detection and characterization.

Code is located in:

`workflows/virome/`

## Data availability

Raw sequencing reads, reference databases, intermediate files, and generated results are not stored in this repository.

The repository contains only analysis scripts, configuration files, and documentation.
